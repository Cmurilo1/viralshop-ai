# ViralShop AI - Plataforma de Agentes LLM para E-commerce

> Case para vaga Pessoa Desenvolvedora - Grupo Boticário. Arquitetura multi-agentes com IA Generativa.

Live Demo: https://viralshop-ai.vercel.app  
Repo: https://github.com/cmurilo1/viralshop-ai

## 🚀 O Problema que Resolvo

Aumentar conversão e reduzir tempo operacional no e-commerce do Boticário com agentes LLM autônomos.

- Agente de Copy Viral (PRONTO): Gera descrições de Malbec, Liz, Egeo com tom viral para Instagram/TikTok Shop.
- Agente de Atendimento RAG (roadmap): Responde dúvidas com base de conhecimento, reduz suporte em 70%.
- Agente de Insights (roadmap): Analisa vendas e sugere produtos virais.

## 🛠️ Stack da Vaga

Next.js 14 (App Router), TypeScript, Tailwind CSS, Vercel AI SDK, OpenAI API, Jest, Vercel CI/CD
